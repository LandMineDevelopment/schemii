# Changelog

## 0.2.0 - 2026-08-23

- Add Schemer as a supported sibling application with shared profiles, scoped metadata authority, structured analytics, dashboards, retained results, and optional private AI.
- Add explicit cross-platform `schemer` and `schemer-ai` launcher modes with stable instance ports, all-service health waits, one shared application image, and primary-Schemer URL handling.
- Add one post-seed shared tutorial-profile initializer and one pure shared profile-document validator used by runtime storage and recovery.
- Add coordinated, marker-bound backup and destructively confirmed restore for shared config, byte-exact Schemii schemas/layouts, Schemer dashboards/layouts, metadata PostgreSQL, and all five instance credentials, including exact version-aware metadata verification from versions 10 through 13, migration-before-commit, pre-commit rollback, and durable post-commit forward cleanup.
- Add explicit, non-destructive, witness-verified adoption for the exact historical unlabeled config/schema volume pair, with owner-only identity manifests enforced by recovery and uninstall on both launcher platforms.
- Harden PostgreSQL execution, migration, Console, metadata ownership, AI policy, cancellation, result-size, and stale-state boundaries across both applications.
- Add deterministic version-1 dashboard compatibility and metadata migrations through version 13, including atomic deleted-chat cleanup of operation-owned usage evidence while retaining application audit transitions.
- Add pinned container foundations, exact runtime version/revision reporting, private-data inspection of final packages and image filesystems, and explicit promotion of one CI-built/tested immutable artifact set without mutable `latest` artifacts.

This is the first release with supported Schemer operations. Review `docs/RELEASE_CHECKLIST.md` before selecting and promoting a successful main-branch candidate.
