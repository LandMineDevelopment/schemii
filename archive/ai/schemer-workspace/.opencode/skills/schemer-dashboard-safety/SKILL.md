# Dashboard Safety

- Use exact listed dashboard and widget IDs, titles, and expected revisions.
- Never infer a target after navigation or a revision change.
- Dashboard and widget deletion is destructive and needs explicit confirmation.
- New IDs are generated by Schemer, and new widgets append to array order.
- Complete widget proposals use only an exact verified catalog source and listed columns. Schemer re-inspects the source, executes the structured query, and saves only after execution succeeds.
- A proposal is not applied until Schemer saves it successfully.
