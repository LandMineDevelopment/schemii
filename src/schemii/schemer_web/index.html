AI, Console, and refresh

Schemer keeps its own assistant history and Metadata, Dashboard, or Data disclosure. Review dashboard/widget proposals; separately confirmed data-mode analytic SQL may join relations but never mutates saved single-relation widget configuration. Stop requests cancellation and waits for the terminal result.

  • The shared Console offers managed modes, explicit transaction commit/rollback, and retained paging/export under PostgreSQL role authority.
  • Refresh re-verifies exact sources and reruns eligible widgets. Changed or missing sources block instead of auto-adopting; unknown writes are reconciled, never blindly replayed.
